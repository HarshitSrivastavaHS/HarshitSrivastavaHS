01Robotics + vision-language AI

Language-guided humanoid manipulation

A simulated Unitree G1 that turns varied language instructions into grounded, validated manipulation actions inside MuJoCo.

  • Integrated a locally deployed Qwen2.5-VL-7B perception pipeline with OpenCV refinement.
  • Built structured planning, inverse-kinematics motion, contact-aware grasping, recovery, and visual verification.
  • Created reproducible scenario evaluation, JSONL evidence, and 33 automated tests.

02Embedded system

Wearable fall detection device

Firmware for an STM32L4S5 wearable that classifies falls from accelerometer and gyroscope data, stores events, and exports them to a phone through NFC.

  • Implemented a five-state detector with jitter rejection and a prolonged-inactivity check.
  • Wrote a four-sample X/Y/Z moving-average filter in ARM Thumb assembly.
  • Encoded fall count, uptime, and timestamps as an NDEF URI for the web dashboard.
STM32CARM ThumbIMUNFC/NDEF
03Autonomous robotics

Search-and-rescue robot

A TurtleBot3 system that maps an unknown maze, explores frontiers, interrupts navigation for heat detections, and resumes after handling a target.

  • Integrated ROS 2 Humble, SLAM Toolbox, Nav2, LiDAR, an AMG8833 thermal array, and GPIO actuation.
  • Extended a frontier-exploration node to manage heat-source goals and avoid revisits.
  • Tuned the real robot’s navigation stack and built isolated sensor and actuator test utilities.
ROS 2Nav2SLAMRaspberry PiThermal sensing
04FPGA + digital logic

K-Map simplifier and visualiser

A Basys 3 FPGA interface for entering three-variable truth tables and moving between K-Maps, Boolean expressions, and gate diagrams in real time.

  • Built switch input, SOP/POS selection, canonical-expression generation, and mode-aware control.
  • Created the 96×64 OLED pixel pipeline, reusable character renderer, themes, and cell highlighting.
  • Integrated independently developed submodules through the top-level design.
VerilogBasys 3OLEDSOP/POSVivado
05Game + creative software

UniQuest

A two-person NUS-themed platformer built in Godot 4, with original systems and assets across desktop, web, and Android.

  • Designed reusable character state machines, combat, weapons, progression, and a global game manager.
  • Built JSON persistence with migration support, mobile controls, customization shaders, and automated GUT tests.
  • Created original game assets including pixel art, background music, and sound.
